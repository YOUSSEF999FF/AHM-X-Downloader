# AHM X Downloader V4 — دليل عربي

مشروع بوت تيليجرام + Mini App بواجهة عربية، وBackend واحد يعمل كـ **Render Web Service**.

## المزايا

- ملفات مستقلة لمعالجة YouTube وFacebook وInstagram وباقي مواقع `yt-dlp` المدعومة.
- اختيار جودة الفيديو، عرض معلوماته والصورة المصغرة، واستخراج MP3 عند دعم المصدر.
- شريط تقدم، إلغاء التنزيل، وسجل تنزيلات كامل مع تحميل صفحات أقدم.
- شريط استخدام يومي يوضح المكتمل والنشط والمتبقي، مع حد عام وحد مخصص لكل مستخدم.
- لوحة مالك/مشرف: تشغيل الصيانة، تفعيل/إيقاف المنصات، تعديل الجودة والحجم والحد اليومي وعدد التنزيلات المتزامنة، وإدارة المستخدمين.
- المالك فقط يمكنه إضافة/إزالة المشرفين.
- سجل أعطال يتضمن رقم تشخيص وStack Trace داخل لوحة الإدارة، مع تنقيح أولي للأسرار.
- التنبيه عند تفاعل المستخدمين أثناء الصيانة، وحذف الملفات المؤقتة، ووضع علامة فشل على المهام التي تعطلت بسبب إعادة تشغيل الخدمة.
- حفظ السجل وإعدادات الإدارة في SQLite على قرص Render الدائم عند استخدام إعداد Blueprint المرفق.

## النشر على Render

1. فك ضغط ملف ZIP، ثم ارفع **محتويات مجلد المشروع** إلى جذر مستودع GitHub. تأكد أن `render.yaml` في جذر المستودع.
2. في Render اختر **New → Blueprint**، ثم اربط المستودع وراجع الموارد قبل تأكيد الإنشاء.
3. ملف Blueprint يطلب **Starter Web Service مدفوعًا وقرصًا دائمًا 1 GB** على `/var/data`. قد يترتب على إنشاء الموارد رسوم. راجع الأسعار الحالية في Render قبل التأكيد. الخدمة المجانية لا توفر قرصًا دائمًا؛ عند استخدام خدمة مجانية قد لا يبقى سجل SQLite بعد إعادة التشغيل أو إعادة النشر.
4. أدخل `TELEGRAM_BOT_TOKEN` من `@BotFather` و`OWNER_ID` الرقمي الخاص بالمالك في Environment Variables. يتم توليد `WEBHOOK_SECRET` بواسطة Blueprint.
5. بعد النشر افتح `https://اسم-الخدمة.onrender.com/health`. افحص `checks.database` و`checks.temp_storage` وإصدار Node وFFmpeg وألا تكون قيمة `yt_dlp_ejs` هي `missing`.
6. افتح البوت وأرسل `/start`. افتح Mini App من الزر الرسمي، ثم جرّب رابط فيديو عام قصير تملك حق تنزيله.

## أهم متغيرات البيئة

- `TELEGRAM_BOT_TOKEN`: التوكن من BotFather، سرّي.
- `OWNER_ID`: رقم حساب تيليجرام الرقمي للمالك.
- `ADMIN_IDS`: أرقام مشرفين أوليين اختيارية، تُقرأ لتهيئة قاعدة بيانات الإدارة عند أول إنشاء فقط. بعد ذلك إدارة المشرفين تتم من لوحة المالك.
- `WEBHOOK_SECRET`: سر الـ webhook؛ Blueprint ينشئه تلقائيًا.
- `DB_PATH` و`DATA_DIR` و`DOWNLOAD_DIR`: مسارات التخزين.
- `COBALT_API_URL` و`COBALT_API_KEY`: اختياريان فقط عند توفر نسخة Cobalt تملكها أو لديك إذن باستخدامها. لا تستخدم مثيلًا عامًا لطرف ثالث دون إذن.

## الأوامر

- `/start` — شاشة البداية والـ Mini App والحد اليومي.
- `/help` — شرح الاستخدام.
- `/id` — رقم تيليجرام.
- `/history` — أحدث التنزيلات.
- `/cancel` — إلغاء العملية النشطة.
- `/panel` — لوحة الإدارة.
- `/status` — إحصاءات الخدمة.
- `/maintenance on` و`/maintenance off` — وضع الصيانة.
- `/set KEY VALUE` — تعديل إعداد مدعوم.
- `/admin add USER_ID` و`/admin remove USER_ID` — المالك فقط.
- `/errors` — أحدث الأعطال؛ العرض التفصيلي للـ Stack Trace موجود في Mini App.

## ملاحظة مهمة عن YouTube

يُستخدم `yt-dlp` مع Node.js و`yt-dlp-ejs`. مع ذلك، قد يرفض YouTube الطلبات من عنوان IP الخاص بالاستضافة برسالة `Sign in to confirm you're not a bot` حتى لو كان الفيديو عامًا. هذه فئة أخطاء موثقة في مستودع yt-dlp: https://github.com/yt-dlp/yt-dlp/issues/15865. لو ظهر هذا الرفض، فالتوافق المحلي وحده لا يضمن الحل. يوجد خيار Cobalt إضافي فقط عند ضبط عنوان نسخة تملكها أو لديك تصريح لاستخدامها. المشروع لا يجمع Cookies ولا يشغّل تسجيل الدخول نيابة عن المستخدم ولا يتجاوز التحقق أو القيود.

## الفحوصات

شُغّلت اختبارات SQLite (الحصة اليومية، السجل، إدارة المستخدمين، واستعادة المهام المقطوعة) وفحوصات تركيب Python وJavaScript وYAML ومطابقة عناصر HTML. **لم يتم إجراء اختبار تنزيل حي باستخدام توكن تيليجرام أو حساب Render الخاص بك**؛ اختبار رابط حقيقي بعد النشر ضروري.

## بنية الملفات

- `app.py`: FastAPI، webhook، أوامر تيليجرام وواجهات API.
- `service.py`: طابور التنزيل، التقدم، حدود التزامن والتنظيف.
- `store.py`: قاعدة البيانات، المستخدمون، السجل، الحصص والمشرفون.
- `diagnostics.py`: رقم الخطأ وStack Trace.
- `security.py`: التحقق من توقيع جلسة Telegram Mini App.
- `downloader/youtube.py`: معالج YouTube.
- `downloader/facebook.py`: معالج Facebook.
- `downloader/instagram.py`: معالج Instagram.
- `downloader/generic.py`: باقي الروابط المدعومة.
- `downloader/cobalt.py`: موصل اختياري لنسخة Cobalt مصرح بها.
- `web/`: واجهة Mini App.
- `render.yaml` و`Dockerfile`: ملفات النشر.
