# AHM X Downloader V4 — Bot + Mini App

A modular Telegram video downloader project built as a **Render Web Service**. It includes a Telegram webhook, an Arabic-first Mini App, platform-specific downloader modules, quota controls, admin tools, diagnostics, and paginated download history.

## Highlights

- Separate handlers: `downloader/youtube.py`, `downloader/facebook.py`, `downloader/instagram.py`, and `downloader/generic.py`.
- `yt-dlp` + `yt-dlp-ejs` + Node.js 22 for extraction on supported public URLs.
- Optional Cobalt fallback, configured only through `COBALT_API_URL` pointing to an instance you operate or are authorized to use. No public hosted API is hard-coded.
- Quality selection, estimated size, thumbnail and title preview, MP3 option, progress bar, cancellation, 47 MB default cap, and automatic temporary-file cleanup.
- User accounts, blocked-account controls, global and per-user daily limits, live concurrency control, maintenance mode, owner notifications, and owner-only admin-management controls.
- Error IDs and stack traces in the admin Mini App, plus `/health` runtime/dependency checks.
- Full paginated SQLite history on the configured persistent disk.

## Deploy to Render

1. Download the ZIP, unzip it, and upload **the contents of this folder** to the root of a new GitHub repository. `render.yaml` must be at repository root.
2. In Render, choose **New → Blueprint** and connect the repository.
3. Review the Blueprint resources before confirming. The included Blueprint uses a **paid Starter Web Service and a 1 GB persistent disk** so the download history, user settings, quotas, and diagnostics persist across deploys. Applying it can create paid resources; check Render's current price before creating them. Free Render web services cannot attach persistent disks. Current note: https://render.com/docs/free.
4. Set `TELEGRAM_BOT_TOKEN` to the token from `@BotFather` and `OWNER_ID` to your numeric Telegram user ID. Do not paste these secrets into source code or commit them to GitHub. `WEBHOOK_SECRET` is generated by the Blueprint.
5. After the first deploy, open the HTTPS service URL and check `/health`. Look for `checks.database: ok`, `checks.temp_storage: ok`, a Node version, `yt_dlp_ejs` not `missing`, and `ffmpeg` available.
6. Configure the HTTPS domain for the bot's Mini App in BotFather if Telegram requests it. Open the bot and send `/start`, then try a short public video you have permission to download.

## Environment variables

Required:

- `TELEGRAM_BOT_TOKEN`
- `OWNER_ID`
- `WEBHOOK_SECRET` (generated in the Blueprint)

Optional:

- `ADMIN_IDS`: comma-separated numeric user IDs to seed as admins.
- `COBALT_API_URL`: your own or authorized Cobalt API instance, if you have one.
- `COBALT_API_KEY`: optional API key for your private/authorized Cobalt instance, set directly in Render Environment Variables. Do not publish it.
- `DB_PATH`, `DATA_DIR`, `DOWNLOAD_DIR`, `MAX_UPLOAD_MB`, `YTDLP_NODE_PATH`, `LOG_LEVEL`.

## Commands

- `/start` — welcome screen and Mini App button
- `/help` — usage and commands
- `/id` — your Telegram numeric ID
- `/history` — recent downloads
- `/cancel` — request cancellation of your active download
- `/panel` — admin controls for authorized admins
- `/status` — admin statistics
- `/maintenance on|off` — enable/disable maintenance
- `/set KEY VALUE` — change a supported setting, e.g. `/set daily_limit 12`
- `/admin add USER_ID` / `/admin remove USER_ID` — owner only
- `/errors` — recent diagnostics for admins

## YouTube caveat

The code tries `yt-dlp` first and includes the EJS/Node components. YouTube can still return `LOGIN_REQUIRED` / “Sign in to confirm you're not a bot” for hosted server IPs, even when the URL is public and dependencies are installed. This is a known upstream issue category; example: https://github.com/yt-dlp/yt-dlp/issues/15865. If that happens, check the diagnostic log. An optional Cobalt fallback can be used only when you configure a self-hosted/authorized instance. This project does not collect personal cookies, automate sign-in, or attempt to bypass a login or anti-bot check. Some videos/platform URLs may remain unavailable from Render.

## Local checks

With the project dependencies installed, run:

```bash
python -m unittest discover -s tests -v
python -m compileall -q .
node --check web/app.js
```

`/health` is a runtime check; it does not prove that every social platform permits a particular URL. Live end-to-end downloading must be verified after deployment because platform responses and hosting IP reputation can change.
